# EmbodyMe

> EmbodyMe, Inc. is a Tokyo-based AI company building real-time neural rendering and 3D dense face-tracking technology for photorealistic digital humans. Its DigiSelf platform turns a single photo into a lifelike AI avatar that speaks from text or audio in dozens of languages, in both pre-recorded video and sub-second real-time interactive modes. Developers drive avatars over the DigiSelf Realtime API (REST + WebSocket).

This llms.txt was GENERATED by the API Evangelist enrichment pipeline (2026-07-19) from the public EmbodyMe/DigiSelf surface and the official digiself-realtime-api-sample repository. No provider-published llms.txt was found.

## API

- [DigiSelf Realtime API](https://digiself.tech/en/): REST + WebSocket API for driving real-time photorealistic AI avatars into LiveKit rooms and Google Meet meeting bots. Base URL https://api.digiself.tech/api. Realtime API host https://realtime-api.digiself.tech. Stream API WebSocket wss://stream-api.digiself.tech.
  - Auth: x-api-key request header (DigiSelf Business plan). See authentication/embodyme-authentication.yml.
  - Create bot: POST /bots -> { job_id }. Poll: GET /bots/wait/{job_id}?timeout=120. See conventions/embodyme-conventions.yml.

## Products

- DigiSelf: photorealistic AI avatar videos from text/audio, real-time and pre-recorded.
- xpression camera: real-time virtual camera for Zoom, Teams, Meet, Twitch, YouTube.
- xpression chat: interactive conversations with AI characters from a single photo.
- xpression avatar: selfie-to-avatar with real-time facial sync.
- Real-time AI Video Generation SDK: cross-platform (iOS, Android, Windows, Mac).
